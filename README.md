# Agregator-Events-Provider-API
___
Приложение предствялет собой аггрегатор для уже существующего API. Предоставляется дополнительный функционал, которого нет в изначальном веб-интерфейсе существующего проекта.
___
При запуске приложения, в `lifespan` запускается две сущности:
+ `scheduler` - задача которого раз в сутки, а именно в нули запускать синхранизацию данных по событиям;
+ `worker` - задача котрого постоянно мониторить таблицу `outbox` на наличие ивентов с статусом `PENDING`, если он их находит, он обрабатывает их.
